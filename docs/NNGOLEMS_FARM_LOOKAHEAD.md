# Farm Demo lookahead verification
The original Farm Demo assessment detected 25 geometric groups and 1,571 deferred verification steps. The legacy structure pilot declined that job. With lookahead enabled, each component retains its deferred checks; all ordinary physical steps in that component precede its verification steps. Matching vanilla results still must be confirmed by the server, and a mismatching check is never completed. This is a new physical experiment, not a guarantee that every connected machine is independently buildable. Cross-component dependencies, unsupported states, and route failures remain possible. The new Farm-only workflow records group sizes, occupied volumes, deferred counts, active groups, prepared schedules and final exact block accuracy.
