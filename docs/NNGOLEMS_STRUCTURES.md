# NNGolems independent structure pilot

Opt in on a new team job with `GOLEMS_NN_STRUCTURES=true` (or JVM property `-Dgolems.nn.structures=true`). Default off until physical validation. The planner groups actual effective schematic steps conservatively, including same-cell water passes and multiblock companions. Cells within two blocks on each axis are merged; shared roads/foundations are intentionally not segmented. Group order follows first original index. All claims, staffing and local zone assignments are gated to the active group; no original saved index changes. Existing completion accounting determines when to advance. Deferred verification, warehouse jobs, height/material rules and conflicting restored claims fall back to the ordinary planner. Individual groups use the existing Y/water/ceiling dependency policy; no team X/Z pilot or neural training is enabled here. Unit tests cover partition, rotation, progress and companion retention. Physical benchmark still required.
