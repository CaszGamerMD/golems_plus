# Structure lookahead (experimental)
Enable GOLEMS_NN_STRUCTURES=true and GOLEMS_NN_STRUCTURE_LOOKAHEAD=true. Order is ascending distinct occupied non-air cells, counting companions and deduplicating water passes. Ties retain original order. First active group is planned synchronously. Once a real builder claim exists, immutable future schedules are computed off-thread and published per group. If a group finishes before its successor is prepared, compute on demand. Roster, job, depot or effective-plan changes invalidate cached schedules. Execution retains Y/support/water gates, with the cheapest of four in-layer X/Z sweeps by geometry-only travel proxy. The single-builder vertical advisor is evaluated but not executed for teams. Deferred verification and shared-connected terrain retain conservative fallback. This is not neural training or proof of optimality.
