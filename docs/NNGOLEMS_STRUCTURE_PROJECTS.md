# Structure projects and nonblocking commissioning
The experimental lookahead mode attaches elevated satellites to a much larger lower structure when at least 75% of the satellite's occupied X/Z columns have nearby occupied columns below, and the owner is unambiguous. The vertical gap is unrestricted. It does not merge lateral neighbors merely because bounding rectangles overlap. This keeps floating villager platforms in the farm's project before sorting by occupied volume.
All ordinary material-backed tasks in every project are scheduled before any deferred physics checks or unsupported no-item tasks. The final commissioning tail still verifies real states, never fakes completion, and can remain pending for the player. Redstone components are placed as ordinary blocks when supported; functioning circuits/moving states are not the construction objective. Farm results report exact physical accuracy and ordinary task completion separately, with a 99% ordinary target. Route stalls can still block ordinary tasks; this policy alone does not fix them.
