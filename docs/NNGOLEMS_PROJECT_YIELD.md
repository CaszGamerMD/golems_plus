# NNGolems project yield after exhausted crew recovery
This opt-in pilot sets GOLEMS_NN_STRUCTURES=true, GOLEMS_NN_STRUCTURE_LOOKAHEAD=true, GOLEMS_NN_PROJECT_YIELD=true. After two unsuccessful whole-crew recovery attempts, when all registered golems have physically returned to OnSite, unloaded, and have no active claims, the Planner may move to another unfinished ordinary project. Block indices, material reservations, verified placements and job total are never marked finished by this transition. The crew's staged claims are cleared and the zone schedule is rebuilt for the next structure. Once the other ordinary projects have been visited, any unfinished construction is revisited before redstone/fluid commissioning. If no alternative remains, the original recovery rules apply. The fallback does not alter conventional main and defaults off. The test logs [NN PROJECT YIELD] and separate physical correct/ordinary counts so a route stall cannot be called completion.
