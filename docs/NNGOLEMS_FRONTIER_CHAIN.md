# Chained staging after Farm Demo scout trial

The first *activated* staging scout A/B on 2026-11-16 reached 411/13,143 physically correct Farm Demo blocks with staging, versus 321/13,143 in the matched no-staging control. 6 scouts were recruited, 9 short ground legs began, 8 arrived, and one aborted almost immediately. Both runs terminated NO_WORK_PROGRESS after 25 and 26 retreat starts respectively. This is an encouraging single-trial outcome, not a statistically established success or a near-completed build.

The trace revealed an orchestration problem: each successful staging waypoint discarded the active leg and returned control to ordinary work selection, which may immediately call the OnSite return route if the worker still cannot plan a direct safe work stance. The new staging pilot can now continue the *same pending target* through up to eight successively shorter, real supported 6-12-block legs without releasing control to idle return between each leg. The final leg still returns to the ordinary safety-checked placement planner. No fake placement, distant teleport, air path, block collision bypass, new supplies, or extra worker beyond the existing scout is introduced.

One transient exact-route failure no longer cancels a staging leg in a single five-tick callback; the navigator has a brief 40-tick retry window, bounded by physical progress and total leg expiry. Unreachable or physically unsupported waypoints still abort. All enhancements are opt-in via GOLEMS_NN_FRONTIER_STAGING and remain isolated to NNGolems. The new A/B asserts both scout recruitment and an actual chained continuation while recording exact world correctness, completed ordinary work and physical movement.
